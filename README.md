# 🏦 ATM Management System (Python)

## 📌 Description

This is a simple ATM simulation program written in Python.
It allows users to perform basic banking operations like checking balance, depositing money, and withdrawing money.

---

## 🚀 Features

* 💰 Check Account Balance
* ➕ Deposit Money
* ➖ Withdraw Money
* ❌ Validation for invalid inputs (negative amount, insufficient balance)

---

## 🛠️ Tech Used

* Python (Core Python concepts)
* Functions
* Conditional Statements

---

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/ayushpatel87490-jpg/ATM--main.git
   ```

2. Open the project folder:

   ```bash
   cd ATM--main
   ```

3. Run the program:

   ```bash
   python main.py
   ```

---

## 📂 Project Structure

* `main.py` → Main program file
* Functions used:

  * `show_balance(balance)` → Displays current balance
  * `deposit()` → Handles deposit logic
  * `withdraw(balance)` → Handles withdrawal logic

---

## ⚙️ How It Works

* The program starts with a balance of ₹0
* User can choose options:

  * Check balance
  * Deposit money
  * Withdraw money
* Input validation is applied:

  * ❌ Negative amounts are not allowed
  * ❌ Cannot withdraw more than available balance
